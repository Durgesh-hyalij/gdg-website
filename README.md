Why are we creating these?

Think of each folder as having a specific responsibility:


| Folder       | Purpose                                    |
| ------------ | ------------------------------------------ |
| `components` | Reusable UI like Navbar, Footer, EventCard |
| `pages`      | Public pages like Home, About, Events      |
| `layouts`    | Common page layouts                        |
| `firebase`   | Firebase configuration                     |
| `services`   | Functions for talking to Firestore/Storage |
| `hooks`      | Custom React hooks                         |
| `context`    | Global state such as logged-in user        |
| `admin`      | Everything related to Admin Panel          |
| `student`    | Everything related to Student Dashboard    |
| `utils`      | Small helper functions                     |
| `assets`     | Images, logos, etc.                        |
